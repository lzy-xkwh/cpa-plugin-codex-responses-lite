# Security Policy

## Supported versions

Security fixes are provided for the latest released version.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting or a private security advisory for this repository. If neither is available, open an issue asking the maintainers for a private contact channel, but do not include exploit details, credentials, or production configuration in the public issue.

The plugin should never receive or store provider credentials. Reports involving exposed secrets should also rotate those secrets through the affected provider immediately.
